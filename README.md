# Learning Basic Maths Through Interactive AR Gameplay

## Project Overview

This project is an augmented reality mobile application designed to help primary school students practise basic mathematics. The application uses Unity and AR Foundation to display simple 3D objects and arithmetic questions through a phone camera.

## Final Scope

The final prototype focuses on a small set of core features:

- AR camera scene
- 3D object placement
- Addition questions
- Answer buttons
- Correct/incorrect feedback
- Simple score counter

Subtraction will be included only if the addition feature is stable.

## Out of Scope

The following features were removed due to time limitations:

- User accounts
- Database storage
- Teacher dashboard
- Multiple difficulty levels
- Advanced animations
- Analytics

## Technologies

- Unity
- AR Foundation
- C#
- GitHub
- iPhone for testing
