# Learning Basic Maths Through Interactive AR Gameplay

## Project Overview

This project is an augmented reality educational game designed to help primary-school-level learners practise basic arithmetic through interactive gameplay. The application was developed using Unity, C#, AR Foundation, and AR raycasting.

The user selects a maths mode, scans a surface, places a robot into the AR scene, reads the maths question displayed above the robot, and shoots the moving answer enemy that shows the correct number.

## Final Prototype Features

The final prototype includes:

- Title screen with four arithmetic modes:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- AR surface scanning
- Crosshair-based robot placement
- Maths question displayed above the robot
- Readable white question background
- Colour-changing countdown timer ring
- Numbered floating answer enemies
- Moving enemy objects around the robot
- Tap-to-shoot raycast interaction
- Correct and incorrect answer feedback
- Score tracking
- Back-to-main-menu button
- Final score screen
- Play Again and Main Menu options

## Project Scope

The project was developed as a minimum viable prototype. The aim was not to build a complete commercial learning platform, but to demonstrate how augmented reality and game interaction can support basic maths practice.

## Out of Scope

The following features were excluded due to time and scope limitations:

- User accounts
- Database storage
- Teacher dashboard
- Saved progress
- Advanced analytics
- Multiplayer features
- Detailed learner profiling
- Full classroom deployment

## How the Game Works

1. The user opens the app.
2. The user chooses a maths mode.
3. The app scans for a flat surface.
4. The user taps to place the robot at the crosshair.
5. A maths question appears above the robot.
6. Numbered answer enemies appear around the robot.
7. The user taps the screen to shoot the correct answer.
8. The score updates after correct answers.
9. The timer ring changes colour as time runs out.
10. The game ends with a final score screen.
